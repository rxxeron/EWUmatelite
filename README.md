# EWUMate Lite

A lightweight JavaFX desktop companion application for EWUMate students, natively interacting with the Supabase backend. It features native Windows UI components, a scheduling system mapping makeup/cancelled events, and the dashboard rules consistent with the mobile version.

## Setup & Requirements

- **Java Development Kit (JDK) 17** or higher
- **Apache Maven** (for dependency resolution and building)
- The project runs entirely on Maven, ensuring consistent execution across devices.

## Running the Application Locally

You can launch the application directly from the source code without compiling a distributable installer using the `javafx-maven-plugin`:

```bash
mvn clean javafx:run
```

## Compiling for Distribution

To compile the application into a standalone shaded executable JAR (which bundles all required libraries like PostgreSQL, JSON handling, and JavaFX SDK):

```bash
mvn clean package -DskipTests
```

The output will be found in the `target/` directory as `EwuMateLite-1.0-SNAPSHOT.jar`.

## Generating a Windows Native Installer (.exe)

Once the shaded JAR is compiled, you can bundle it into a standalone `.exe` installer (requiring no external Java installations from the end-user) using the `jpackage` utility. Ensure you have the `EwuMateLite\runtime` custom JRE prepared.

```bash
# 1. Prepare input directory
New-Item -ItemType Directory -Force target\deploy\input

# 2. Copy the JAR
Copy-Item -Path "target\EwuMateLite-1.0-SNAPSHOT.jar" -Destination "target\deploy\input\" -Force

# 3. Use JPackage to bundle the executable installer
jpackage --type exe --name "EwuMateLiteFinal" --input "target\deploy\input" --main-jar "EwuMateLite-1.0-SNAPSHOT.jar" --icon "src/main/resources/com/ewumatelite/logo.ico" --win-dir-chooser --win-menu --win-shortcut --dest "target\deploy\output" --runtime-image "EwuMateLite\runtime"
```
> Note: If building the `.exe` throws an icon error, ensure the path strictly matches your repository. If you don't have a `.ico`, simply omit the `--icon` parameter.

## Repository Notes

Gradle files have been removed in favor of the unified `pom.xml`. To commit to source control, ensure all autogenerated output (`target/`, IDE folders `.idea`, `.vscode`) are excluded via your `.gitignore`.
